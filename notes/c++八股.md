# C++ 面试八股速记

## 1. 虚函数是什么？原理是什么？

虚函数是 C++ 实现运行时多态的机制，基类函数加 `virtual` 后，派生类可以 `override`，通过基类指针或引用调用时，会根据对象真实类型决定最终调用哪个函数。主流编译器通常通过 `vptr + vtable` 实现：对象里的 `vptr` 指向实际类型的虚函数表，再根据槽位找到函数地址。代价是对象多一个 `vptr`、调用多一次间接访问，并可能影响内联和分支预测。多态基类的析构函数一般要声明为 `virtual`，否则通过基类指针 `delete` 派生类对象会有问题。

---

## 2. 哪些函数可以声明为虚函数？

普通非 `static` 成员函数和析构函数都可以声明为虚函数，`public / protected / private` 不影响 `virtual`。构造函数不能虚，因为对象还处于构造阶段；`static` 成员函数不能虚，因为没有 `this` 指针、不属于具体对象；成员函数模板不能虚，因为模板实例数量和版本无法提前固定到虚表槽位中。速记：**构造不能虚、static 不能虚、成员模板不能虚。**

---

## 3. 函数模板、类模板、模板特化

模板是 C++ 的编译期泛型机制，函数模板根据模板参数生成不同函数，类模板根据模板参数生成不同类型。模板特化是在通用模板之外，对特定参数提供特殊实现；全特化固定全部参数，类模板还支持偏特化，而函数模板不支持偏特化，通常用重载实现类似效果。CUDA 中常把数据类型、`BLOCK_SIZE`、tile size 等写成模板参数，让编译器在编译期展开和优化。

---

## 4. 内存对齐

内存对齐是让对象起始地址满足一定的 alignment，例如 `int` 通常 4 字节对齐。这样做主要是为了让 CPU 或 GPU 更高效地访问内存，避免一个数据跨多个访问单元导致多次读取和拼接，因此本质上是**空间换时间**。结构体中编译器会自动插入 `padding` 保证成员和结构体整体对齐；CUDA 中还要结合 `float4` 等 vectorized load 和 memory coalescing 一起考虑。

---

## 5. const、constexpr、inline 有什么区别？

`const` 主要表示“不能修改”，但不代表一定在编译期确定；`constexpr` 表示变量或函数具备编译期求值能力，`constexpr` 变量本身也是 `const`，但 `constexpr` 函数传入运行时参数时也可以运行时执行；`inline` 主要与函数内联有关，但写了 `inline` 并不保证一定展开，不写也可能被编译器自动内联。速记：**const 管不能改，constexpr 管能不能编译期算，inline 不保证真的内联。**

---

## 6. 智能指针

智能指针基于 RAII，把资源生命周期和对象生命周期绑定起来，避免手动 `new/delete` 带来的泄漏和重复释放。`unique_ptr` 表示独占所有权，不能拷贝但可以 `move`，开销最小；`shared_ptr` 表示共享所有权，通过 control block 维护引用计数，强引用计数为 0 时销毁对象；`weak_ptr` 不拥有对象、不增加强引用计数，主要用来观察 `shared_ptr` 管理的对象并解决循环引用。一般不需要共享时优先 `unique_ptr`。

---

## 7. 全局、局部、static、const 生命周期

全局变量具有静态存储期，通常从程序开始一直存在到结束；普通局部变量具有自动存储期，执行到定义时创建，离开作用域时销毁；`static` 变量也具有静态存储期，其中局部 `static` 只初始化一次，但作用域仍局限在函数内部；`const` 本身不决定生命周期，只表示对象不能被修改。速记：**全局和 static 看整个程序，局部看作用域，const 只管能不能改。**

---

## 8. 函数指针、指针函数、常量指针、指针常量

函数指针本质是指针，保存函数地址，例如 `int (*p)(int)`；指针函数本质是函数，只不过返回指针，例如 `int* func(int)`；常量指针 `const int* p` 表示指针可以变，但不能通过它修改指向内容；指针常量 `int* const p` 表示指针本身不能变，但可以修改所指向内容。速记：**函数指针是指针，指针函数是函数；常量指针内容不能改，指针常量指针不能改。**

---

## 9. 封装、继承、多态

封装是把数据和行为放在类中，并通过 `public / protected / private` 隐藏内部实现；继承是派生类复用和扩展基类，建立 `is-a` 类型关系；多态是在统一接口下让不同对象表现出不同的行为，其中运行时多态主要通过虚函数实现，编译期多态包括函数重载和模板。速记：**封装隐藏实现，继承建立关系，多态统一接口、不同表现。**

---

## 10. override 和 overload

`override` 是重写，发生在继承体系中，子类重新实现父类的虚函数，属于运行时多态，最终调用哪个版本取决于对象真实类型；`overload` 是重载，通常发生在同一作用域中，函数名相同但参数列表不同，编译器在编译期决定调用哪个版本，属于静态多态。速记：**override = 父子类 + virtual + 运行时；overload = 同名不同参数 + 编译期。**

---

## 11. 线程和进程

进程是资源分配和隔离的重要单位，通常拥有独立的虚拟地址空间；线程是进程内部的执行流，也是 CPU 调度的重要单位。同一进程中的线程共享代码段、全局变量、堆和文件，但每个线程有自己的栈、寄存器和程序计数器。线程通信方便但容易数据竞争，需要锁或原子操作；进程之间通常通过管道、共享内存、消息队列或 socket 等 IPC 通信。

---

## 12. 死锁的四个必要条件

死锁需要同时满足四个条件：**互斥、占有并等待、不可剥夺、循环等待**。互斥表示资源一次只能被一个线程占有；占有并等待表示线程持有资源的同时继续等待其他资源；不可剥夺表示已经拿到的资源不能被其他线程强行抢走；循环等待表示多个线程之间形成首尾相连的等待环。避免死锁的核心就是破坏其中至少一个条件，最常见的方法是统一多个锁的获取顺序，从而破坏循环等待。
